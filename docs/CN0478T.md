# 1.1.0-cn0478T-791D 安装与回退

适配目标为 Volkswagen Passat B8 Variant 的 TechniSat/Preh `3Q0 035 866 C / H41` 导航主机，固件 `MST2_CN_VW_ZR_P0478T`、HMI `H29.319.93`，仪表 `3G0 920 791 D`。基于上游 `v1.1.0` 提交 `5ad10508ec140d77d46dee1e716b4a25de4dca94`。[上游发布说明](https://github.com/perkthefox/mst2-cluster-nav/releases/tag/v1.1.0)

本版是经过本地验证的候选包。默认 CarPlay 画布 `800×480`，物理尺寸声明 `244×146 mm`，SafeArea `(171,71,460,347)`，Zoom-out 默认为 Off。默认帧率上限为 25 FPS，已有的帧率和显示覆盖配置会在更新时保留。新版 Android Auto 地图与 CarPlay 缩小地图的转码输出同为 `800×480`。Android Auto 需要车机已启用相应的 App-Connect 功能。

## 从 Patch1 升级

1. 保留你已验收的 Patch1 安装包与 `mst2-cluster-nav-backup/`。用 `SHA256SUMS.txt` 核对新版 `mst2-cluster-nav-1.1.0-cn0478T-791D.zip`。
2. 解压新版，把包内 `custom/` 合并到 Toolbox 操作卡根目录的 `custom/`。卡上应有 `custom/greenmenu/mst2-cluster-nav.esd` 和 `custom/mst2-cluster-nav/MANIFEST`。
3. 在 GEM 的 `MIB STD2 Toolbox → Customization → GreenMenu` 选择 `Copy custom Green Engineering Menu screens and scripts to unit`，然后重新进入菜单。新版安装器负责校验 `MANIFEST`，所以这次要同时更新菜单脚本。
4. 进入 `Customization → Cluster_Navigation`，选择 `Install / update`。看到安装完成并提示单次 Trial 后，正常重启。
5. 第一轮在车辆停稳时，用有线 CarPlay、Zoom-out Off 检查仪表地图、转向、断连后原厂导航恢复及重连。基础路径确认后，分别检查曲目和封面、缩小地图、Android Auto。一次 Trial 结束后可以用 `Arm another trial boot` 继续验证。`Enable permanently` 适用于你确认实车表现后。

从空白插件环境首次安装时，同样使用第 2 至 5 步。前提是车机已具备可用的 MIB STD2 Toolbox 和可进入的 GEM。

## 回退到 Patch1

在 GEM 可用时，用 **新版菜单的 `Uninstall`** 卸载，重启确认回到原厂。换回 Patch1 的菜单和安装文件，再导入旧菜单并用旧菜单执行 `Install / update`。Patch1 的正式 SD 包内目录是 `sd/custom/`。卸载会清除插件的机内设置，重装后可按需恢复原先的帧率和显示设置。

上游的 SD 禁用标记是放在独立应急卡根目录的零字节文件 `mst2-cluster-nav-disable`。本地模型验证了卡已挂载时的禁用判断。完整车机启动和独立恢复仍需实车条件确认。

## 本地验证的范围

- 以原厂 P0478T JXE 的接口声明编译 HMI，按上游参数编译 ARM 库。以本机测试替身回放导航、曲目及封面逻辑。
- ARM 模型运行编译后的 Hook，检查 CarPlay 显示声明、Type-111 会话、P0478T 原厂接口及 Android Auto 服务注册。VPU 硬件编解码、实际手机会话、MOST 画面和真实仪表媒体显示等待实车验证。
- 以 P0478T 启动文件的副本模拟 Patch1 升级、校验拒绝、Trial、挂载 SD 禁用、卸载和回退。卸载后的三个配置文件与原厂副本逐字节一致。

## 源码与构建

源码沿用上游 `package.sh`，需要本机 clang、LLD、JDK 8 和目标 JXE 对应的编译接口。`VERSION` 决定安装包文件名。Windows 本机复现脚本和证据保存在本次独立工作目录的 `tools/` 与 `evidence/`。
